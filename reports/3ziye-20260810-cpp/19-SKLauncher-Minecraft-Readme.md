# SkLauncher Minecraft

**SkLauncher** is a  Minecraft Java Edition launcher that lets you play without a paid account. Supports all Minecraft versions, Forge, Fabric, NeoForge, Quilt, and OptiFine with a modern interface on Windows, macOS, and Linux.

## Key Features
- Play Minecraft Java Edition  without a paid Microsoft account
- Supports all versions from Beta 1.0 to the latest 1.21.x
- One-click Forge, Fabric, NeoForge, and Quilt mod loader installation
- Custom skin and cape support with skin uploader
- Multi-account support including offline accounts
- OptiFine integration for shaders and better performance
- CurseForge and Modrinth mod browser built in
- Java auto-installer — no manual JDK setup required
- Custom JVM arguments and memory allocation per profile
- Works on Windows 10/11, macOS, and Linux

## Getting Started
1. Download the latest version above
2. Run SkLauncher.exe or the .jar on macOS/Linux
3. Create an offline account or log in with Microsoft
4. Select your Minecraft version and install mod loaders if needed
5. Click Play

## Troubleshooting

**SkLauncher not opening?**
Make sure Java is installed. Download JDK 21 from Adoptium or use the built-in auto-installer.

**SkLauncher download for Linux or Mac?**
Download the .jar file and run with: java -jar SkLauncher.ja


**Mods not loading?**
The mod loader version must match your exact Minecraft version.

## System Requirements
- Windows 10/11, macOS 12 or later, Linux
- Java 17 or 21
- 4 GB RAM minimum, 8 GB recommended for modpacks

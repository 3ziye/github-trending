# What Is DigitalShield-Pay
DigitalShieldPay is an open-source cryptocurrency payment gateway built for businesses that want to accept USDT and other blockchain-based payments. [Sign in](https://ds.pro/pay) and connect to our free payment service in as little as three minutes.

# Why Choose DigitalShield-Pay

DS-Pay (Digital Shield Pay) is a multi-chain, multi-token cryptocurrency payment gateway built on the Digital Shield wallet ecosystem. It provides individuals and merchants with order creation, on-chain transaction monitoring, order status synchronization, and transaction processing capabilities. Through standardized APIs, callback notifications, and a complete merchant dashboard configuration workflow, DS-Pay enables merchants to quickly integrate cryptocurrency payment channels and launch payment services.

- **Non-custodial fund flow**: funds move directly from the payer's wallet to the merchant's receiving address. DS-Pay never takes possession of funds and does not participate in custody, transfers, or settlement.

- **Zero platform fees**: DS-Pay does not charge transaction service fees, helping merchants reduce the operational cost of accepting cryptocurrency payments.

- **Order-level transaction matching**: on-chain payments are accurately linked to merchant orders, with support for manual completion, refunds, and other post-payment handling workflows.

- **Real-time on-chain monitoring**: DS-Pay continuously monitors target network transaction events, synchronizes on-chain payment results, and updates order status automatically.

- **Standardized system integration**: standardized HTTP APIs and asynchronous callback notifications make it easy to integrate with existing business systems.

- **Multi-network compatibility**: DS-Pay supports multiple mainstream networks and a wide range of crypto payment scenarios.

## 功能

以下为 1.3.1 测试版的核心功能。下载以[实时发布索引](https://beatsad.github.io/quiet-tv/latest.json)为准，按电视系统与实际安装包选择适配版本。

| 功能 | 可以做什么 |
| --- | --- |
| 常用应用与排序 | 首页最多 5 个常用应用；长按移动、添加、替换、隐藏及发起卸载，隐藏应用可在应用管理恢复。 |
| 桌面个性化 | 经典／艺术画廊布局，自定义问候语和头像，各项信息与快捷按钮独立显隐。 |
| 天气 | 自动定位、手动选城和手机扫码选城，首页显示当地天气。 |
| 壁纸 | 默认颜色主题、必应每日壁纸、自定义图片和视频；胶囊下拉设置轮播频率，视频声音开关，手机上传可改名。 |
| 桌面屏保 | 与壁纸共用素材，独立选择屏保、空闲进入时间，以及时间和天气显示。 |
| 文件传输 | 进入自动开启局域网收发，浏览本地与 U 盘，预览并导入壁纸；来源方向键直接切换。 |
| 应用管理 | 分类筛选、应用详情、自定义封面；本机 TCP ADB 连接后，按规则和固件能力提供禁用、重新启用、卸载与恢复安装。 |
| 儿童模式 | 隐藏或锁定应用、设置单次或每日使用时长，家长验证与到时休息提醒。 |
| 应用自启 | 开机或待机唤醒进入 Quiet TV 后启动指定应用，按 HOME 返回不重复启动。 |
| 信号源与桌面配置 | 按本机能力打开输入和系统设置；电脑 AI 配置默认桌面或兼容接管，保留原桌面恢复路径。 |
| 应用内更新 | 检查版本、多源下载、完整性与签名校验，由用户确认安装。 |
| 遥控器与本地使用 | 方向键、确定、返回操作，可选按键音；电脑 AI 可按实际能力逐键校准，无需云端账号。 |

从“全部应用 → 桌面设置”进入“桌面显示／看电视／天气设置／应用管理／儿童模式／文件传输／版本更新／诊断日志”。日常桌面、排序、壁纸、天气和封面设置无需 ADB。开发源码新增“看电视 → 搜索与配对”，可用遥控器检测、试开并保存信号源，电脑 AI 使用同一套维护接口；ADB 路径复用已授权的本机连接，未知协议通过辅助识别生成反馈。此能力尚未打包或进行厂商真机验收，详见[信号源配置](docs/agent/inputs.md)。首次桌面接管、必要连接准备、未知固件调查与开机广告处理仍由电脑 AI 按需执行；电视端保留已配置的本机 TCP ADB 日常管理，不提供无线配对界面，电脑已连接不代表应用已获授权。详见[应用管理](docs/APP_MANAGEMENT.md)。

1.3.1 新增文件传输、独立屏保、顶部轮播频率、手机上传改名和首页长按管理，完善电脑校准与维护；修正壁纸选择、家长验证、儿童计时状态和安装预检，改善视频资源交接与返回桌面黑闪。完整内容见 [1.3.1 Release](https://github.com/BeatsAD/quiet-tv/releases/tag/v1.3.1)。

应用内更新清单已上线，首页前台每 24 小时自动检查，可在“桌面设置 → 版本更新 → 检查更新”主动查询（1.3.0 入口为“应用管理”，更旧版本为“关于”）。旧版没有更新入口时先手动安装；同版本不会因构建号不同重复提示升级。详见[应用内更新](docs/UPDATES.md)。

## 安装方式

### 1. 使用 Skill

安装仓库中的[电视桌面切换助手](skills/quiet-tv-switch/SKILL.md)，在支持 Skill 和终端操作的 AI 工具中输入：

```text
请用 $quiet-tv-switch 帮我安装 Quiet TV 并切换电视桌面，保留原桌面和恢复方法。
```

### 2. 使用安装指令

打开[安装指引](https://beatsad.github.io/quiet-tv/)，复制唯一 AI 指令，交给电脑上的 AI 工具执行。安装、升级、修复共用[统一入口](docs/AGENT.md)，恢复时补充“恢复原桌面”；中断后提供原任务目录继续。页面会自动读取[最新版索引](https://beatsad.github.io/quiet-tv/latest.json)，无需填写版本号或随新版本修改指令。

# 中小学·高中知识图谱（数学 + 语文 + 科学 + 英语 + 物理 + 历史 + 地理 + 生物 + 化学）

对齐《义务教育数学课程标准（2022 年版 2025 年修订）》（教育部《中小学课程方案和课程标准日常修订版》，教材〔2025〕1 号）、《普通高中数学课程标准（2017年版2025年修订）》的**必修和选择性必修**，以及《义务教育英语课程标准（2022年版）》一级、二级和三级（7–9 年级）和《普通高中英语课程标准（2017年版2025年修订）》的必修、选择性必修。数学教材是人教版一–九、人教 A 版（2019）必修两册和选择性必修三册；英语按人教 PEP（三年级起点，根据2022年版课程标准修订的新版）三上到六上（四下按 2026 春 pep4x_2026 densify；五下新版未上线暂按现行 peps5x densify；六下按现行 peps6x densify）、人教版 Go for it! 新版七上到九上（九下新版未上线，暂按旧版九年级全一册第 9–14 单元等），以及人教版（2019）高中必修三册和选择性必修四册。初中物理按人教版新版（根据2022年版课程标准修订）八年级上册、八年级下册、九年级全一册，对齐《义务教育物理课程标准（2022年版2025年修订）》；高中物理按人教版（2019年审定）必修第一至三册和选择性必修第一至三册，对齐《普通高中物理课程标准（2017年版2020年修订）》。附**自适应前置诊断**与题库。数学答错会沿先修边从高中、初中一直回溯到具体的小学知识点。英语单独成图，不和数学连边；初中英语会连回小学英语，高中英语主要连回初中英语。物理也单独成图，用到的数学写在知识点的 `mathLinks` 字段里，不算先修边。仓库名仍是 `cn-math-taxonomy`。初中生物按人教版七至八年级单独成图，对齐《义务教育生物学课程标准（2022年版）》第四学段内容要求的公开转述；六三制九年级没有生物课。初中化学按人教版九年级上、下册单独成图，对齐《义务教育化学课程标准（2022年版）》第四学段内容要求的公开转述；六三制化学在九年级开设，不建七、八年级化学点，也不采用五四制全一册。初中语文按统编版七至九年级并入已有语文学科（仍是 `subject=chinese`，编号 `cnc_j`），对齐《义务教育语文课程标准（2022年版）》第四学段学段要求的公开转述（2026-11-06 对照人教社电子书印刷页 14–16；该节没有【内容要求】标题，也未取得教育部 PDF）；小学语文仍是 `cnc_p`。没有高中语文。

**范围：数学高中做到必修和选择性必修，并且只用人民教育出版社 A 版（2019）；英语做到三年级到高中（人教版 2019 必修三册、选择性必修四册）；语文做到小学一至六年级和初中七至九年级（统编版），没有高中语文。** 7.3「复数的三角表示」仍按教材选学处理，没有单独建点。定积分不在选择性必修的内容要求里，没有建点。英语不出听力和口语题。

> 知识点的拆分粒度、掌握标准、诊断题答案，尤其是**先修关系（哪些是 hard、哪些是 soft，甚至某条边该不该存在）都需要一线教师审核**后才能用于教学、诊断或学习路径推荐。小学和初中数学的诊断题有自动核验，初中数学另有盲解复核，小学数学有独立程序复核；**高中题和英语题没有做盲解**，`verify` 和答案来自同一条表达式。小学册次目录和高中章节目录多数不是官方逐页核对。高中数学课标已于 2026-11-06 记下人教社转载 PDF 的印刷页，句子仍是转述。英语语音、词汇、语法已于 2026-11-06 记了人教社电子书或转载 PDF 的印刷页，句子仍是转述。日常表达、读写，以及 PEP、Go for it!、高中 2019 的册次，标了「待核」的不要当成官方原文或页码。初中语文各册目录仍未逐页核对纸质课本。第一至第三学段学段要求已于 2026-11-06 对照人教社电子书印刷页 7–13，第四学段对照印刷页 14–16，库存句子仍是转述，未取得教育部 PDF。小学语文册次的逐课目录这次只抽查到一上修订要点，没有升成官方逐课目录。

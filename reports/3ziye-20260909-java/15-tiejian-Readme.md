# 贴见

原创离线 Android 照片贴纸日历。

## 下载

正式安装包通过 GitHub Releases 发布。进入仓库的 **Releases** 页面，下载最新版本的 `贴见-v*.apk` 即可安装。

当前版本：`1.24.0`（versionCode 25）。

核心功能：

- 贴纸名称、地点、城市、心情和日期记录，不限定饮品或物品类型
- 全应用内置霞鹜文楷子集字体，正文、标题、表单、日期与纪念章保持统一楷体气质
- 相册导入或相机拍摄，照片为必选项
- U2NETP + ONNX Runtime 在手机本地识别主体并移除背景
- 抠图结果保存为带透明通道和白色描边的 PNG 贴纸
- 印记册、月历回看；贴纸直接显示在对应日期下面
- 日历采用周一开头的圆角格布局，当天金色高亮，多枚贴纸显示数量角标
- 月视图和周视图的日期数字均铺满格子并强制水平、垂直居中
- 日历格中的贴纸按安全区域等比例缩放，超宽、超高图片均不会溢出或变形
- 日历下方显示本月贴纸数、地点数与最近一枚贴纸
- 右上角 `M / W` 按钮可切换月视图与本周视图
- 空日期不再响应点击；单枚贴纸进入详情，多枚重叠贴纸打开当天抽屉
- 月视图有记录时不再显示日历下方的操作说明文字
- 当天抽屉采用两列卡片，可查看当天所有贴纸，标题区不显示额外统计
- 抽屉卡片左上角使用圆形“×”删除入口，点击后通过统一圆角弹窗二次确认
- 当天贴纸抽屉不显示无实际功能的星星图标，卡片信息更简洁
- 印记册采用两列邮戳墙
- 印记册不显示背景水印和数量统计，只保留标题与邮戳墙
- 纪念章统一为参考邮戳的十边形轮廓，使用稳定随机的莫兰迪色，并展示名称、英文日期与城市
- 邮戳边框和文字包含稳定随机的缺口、颗粒、褪色与轻微形变，呈现真实盖印的斑驳感
- 邮戳整体与文字采用更松弛的小尺寸排版；未填写城市时底部直接留空
- 印记册不提供删除入口；详情页仍可删除贴纸，并同步删除记录和本地照片文件
- 印记册底部使用纪念语 `Stamp the moment, keep the memory.`
- W 周视图不显示额外收藏卡
- 月视图也移除额外收藏卡，只保留当月统计
- 顶部日期可点击配置“今天”的日期，选择结果会本地保存，新贴纸也会记录到该日期
- 日期配置采用年、月、日三列滚轮，中间选中横条与金色“完成”按钮
- 日期滚轮统一采用数字格式，例如 `2026 / 8月 / 16日`
- 周视图按星期分为七列，同一天的多枚贴纸在该列内纵向排列
- App 启动后直接显示日历，不再经过首页
- 隐藏系统状态栏，并在顶部保留安全留白，避免内容贴近摄像头区域
- 底部导航改为日历与印记册两个胶囊入口，并增加独立圆形加号
- 日历与印记册入口采用统一线性图标，并增加清晰的选中态
- 加号改为参考图风格的全屏快捷创建层，提供“拍照”和“从相册上传”两张纵向卡片及圆形关闭按钮
- 设置页新增“隐私条款”，二级页面分别提供完整的隐私政策和使用条款
- 条款按个人自用场景配置，开发者标识为“贴见个人开发者”，联系邮箱为 949259758@qq.com
- 设置页精简为实际设置项和隐私条款，删除本地 AI、演示数据及本机存储提示文案
- 隐私政策明确照片与 AI 均在本机处理、无账号与服务器上传、分享和删除机制
- “清空所有本地记录”会同时删除记录、原始照片和透明贴纸文件；系统云备份已关闭
- 本机 JSON 数据存储、分享文字、删除与清空
- 详情页可生成 3:4 贴纸纪念卡，弹窗预览后可保存 PNG 或调用系统分享

工程采用 Android 原生 Java，不使用参考 APK 的代码、品牌或素材。当前 APK 包含 arm64-v8a 推理库，适用于主流 64 位 Android 手机。

## 源码与发布约定

- `src/`：Android Java 源码
- `res/`：应用资源与图标
- `assets/fonts/`：内置字体及其许可证
- `ml/u2netp.onnx`：本地抠图模型
- `build.sh`：当前本地构建脚本
- 正式 APK 只上传到 GitHub Releases，不提交进 Git 历史
- `build/`、本地签名证书和生成的原生库均已忽略，避免泄露签名材料

后续迭代先修改源码并提交到 `main` 分支；确认版本后，再构建签名 APK 并创建新的 Release。
